# 0001 Modular Monolith

Estado: Aprobado

Contexto: El producto está en etapa inicial y necesita velocidad con límites claros entre módulos.

Decisión: Iniciar como monolito modular en NestJS.

Consecuencias positivas:

- Despliegue simple.
- Menor sobrecarga operativa.

Consecuencias negativas:

- El escalado es menos granular.

Alternativas consideradas:

- Microservicios desde el día uno.
