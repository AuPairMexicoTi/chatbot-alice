# 0003 Prisma PostgreSQL

Estado: Aprobado

Contexto: Se requiere SQL relacional, migraciones y tipado fuerte.

Decisión: Usar PostgreSQL con Prisma.

Consecuencias positivas:

- Tipado del cliente.
- Migraciones versionadas.

Consecuencias negativas:

- Requiere generación de cliente.

Alternativas consideradas:

- Query builder manual.
- ODM/document store.
